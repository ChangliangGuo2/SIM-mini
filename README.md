# SIM-mini

MicroLED-based miniature microscope for structured illumination and selective excitation.

## Overview

SIM-mini is a miniature fluorescence microscope integrating programmable MicroLED illumination, structured illumination microscopy (SIM), and image-guided selective excitation.
